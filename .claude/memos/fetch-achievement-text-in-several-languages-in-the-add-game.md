# Fetch achievement text in several languages in the Add game wizard

Add game wizard should fetch achievement text in several languages. SteamWebApi.cs:32 sends no 'l=' parameter and AchievementSchemaWriter types displayName/description as plain string, so every wizard-generated schema is english-only and the Achievement text setting can never do anything for those games. Verified live: GetSchemaForGame accepts l=<language>, 31 calls took 4.1s for appid 812140, and 14 of Steam's languages are genuinely localised for it (an unsupported language silently returns english, so detect by comparing the whole schema against english rather than per entry). Only 1 of 11 schemas on this machine is multi-language. KNOW THE CEILING BEFORE BUILDING IT (measured 2026-09-03, appid 812140): this feature cannot reach hidden achievements at all, so for Odyssey it fixes 62 of 93 and leaves 31 in english. Steam publishes NO description for a hidden achievement in ANY language - GetSchemaForGame returns blank for all 31 in each of the 14 languages, and https://steamcommunity.com/stats/812140/achievements/?l=russian redacts exactly the same set, so this is Steam policy rather than a missing parameter. The only source that has them is SteamDB, which the wizard already scrapes for precisely this reason (SteamDbScraper), and SteamDB serves them english-only: scraped via Firecrawl, '?l=russian' returned byte-identical markdown with ZERO cyrillic characters, and the page carries no language control (its 'Russian' strings are currency names in the price table). So the UI must not promise full localisation - a game's popups will be mixed, localised for visible achievements and english for hidden ones, and that is worth saying in the wizard rather than letting it look like a bug. Related: the 'hidden' field memo below is a prerequisite, since without parsing it the app cannot tell 'redacted by Steam, nothing to fetch' from 'this config was generated badly'.
