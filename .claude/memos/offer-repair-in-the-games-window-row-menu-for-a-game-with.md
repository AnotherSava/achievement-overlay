# Offer Repair… in the Games window row menu for a game with config problems

The Games window's config column shows an amber ! when GameList.ConfigProblemsOf finds a problem (list not beside the loaded DLL, achievements without description or icon, save folder not watched). The row's ⋯ menu offers no way to act on it. Proposed 2026-11-11: a Repair… item for rows with problems that re-runs Add game on the game's folder with overwrite allowed (the wizard already asks before overwriting an existing steam_settings). Decide whether Repair… is just Set up… on a configured row, and how it interacts with the SetupRecord a revert relies on (a second run keeps the first run's entries).
